# アーキテクチャ・技術方針

## 基本方針

- ユーザーに見せる画面は**マップ**。日陰の計算は Google Earth 系で行い、結果を Maps に表示する（併用）
- **API なしでも動くデモ版を先に作る**。API キーがあれば API 機能が追加される作りにする
- 経路はアプリ内に表示する（Google マップアプリへ飛ばさない）
- 予算: Google Cloud クレジット約 20 ドル。各 API の無料枠・上限を事前に設定する

## API 調査（11/4 #20 で調査タスク化）

| API | 用途 | 状態 |
| --- | --- | --- |
| Google Maps API（Maps JavaScript / SDK） | 地図表示、スポット表示、アプリ内の経路表示 | ✅ 採用 |
| Google Earth Engine（Google Cloud 経由） | 建物の高さ・3D データから影を計算 | △ 調査中 |
| Solar API | 時間を変えると影が変わる日照解析 | △ 調査中 |
| Routes API | 日陰・屋根・休憩スポットを考慮したルート | △ 調査中 |
| Gemini API | 空席・混雑推定の補助、投稿の分類・集約、レポート生成 | ✅ |
| Firebase | 認証・DB・ユーザー投稿 | △ |

> 「Google Earth API」としか話していない箇所がある。実際に何の製品を使うか（Earth Engine／Photorealistic 3D Tiles／Solar API など）と料金・規約は要確認。

## データ

- 建物データ: AI で 1274 件作成済み（11/4 #21）
- 休憩スポット（ベンチ・水飲み場・屋根・トイレ・ゴミ箱）: 外部データ＋ユーザー投稿
- 空席確率の入力データ: 未定

## 配布

- Android: APK（メンバーが作成可能）
- iOS: Web アプリ
- 両 OS 対応のツールは「重すぎる」ため見送り気味
