# アイデア・仕様

出典は Google Drive の議事録（[sources.md](sources.md)）。凡例: ✅ 確定 ／ △ 検討中 ／ ⚪ 候補 ／ ❌ 見送り・優先度低

## コンセプト

**学生向け休憩スポットAIマップ。** 休憩場所が「ある」ことは競合アプリでも分かるので、**「ベンチがあって、実際にそこに座れるかどうかが分かる」** を解決する軸にする（△ 有力）。

## 課題

- 歩き回っていて休みたいときに、座れる場所・日陰・トイレ・ゴミ箱がすぐ分からない
- 既存アプリへの不満: 有料のものがある／精度が低い／カメラが必要

## 差別化ポイント

1. **カメラ・センサーなしで屋外ベンチの空席確率を AI が推定**（「座れるか分かる」）
2. Google Earth 系 3D データによる**時間別の日陰予測**
3. **AI の予測とユーザーの実投稿を区別して表示**
4. （候補）カレンダー × 歩数 × 天気で、疲れる前に休憩を促す通知
5. （候補）市民投稿 → Gemini で集約 → 人が確認してから行政へ提案

## 競合

| サービス | 特徴 |
| --- | --- |
| スワリポケット | ベンチ約6,000件、年間UU約60万 |
| ひとやすみマップ | ベンチ・公園・給水スポット、歩数計測（2026/7リリース） |
| 東京都クーリングシェルターマップ | 暑さ避難場所 |
| 涼ナビ／すずみば | 涼み場所 |
| VACAN | 店舗・トイレの空き状況（リアルタイム） |
| NAVITIME「ナビゲート日陰マップ」 | 日陰マップは既にある → 日陰だけでは新規性なし |

- 解決する軸を 1 つ決め、その軸に沿って機能を選ぶ
- 案: 35 機能 → 約 10 軸 → 3 つに絞る → 3 アプリ作って比べる（△）
- スライドには「落とした要件とその理由」も載せる（11/4 #20）
